## ⚙️ Configuration & Customization Guide

To personalize this template for another customer:
1. Open the `/data/` directory.
2. Edit `profile.json` with the baby's details (Name, Nickname, Birth Date, Celebration Month).
3. Place baby photos in `/assets/photos/` and map them in `gallery.json`.
4. Update quotes and greetings in `messages.json`.
5. Update milestone records (weight, height, achievements) in `milestones.json`.
